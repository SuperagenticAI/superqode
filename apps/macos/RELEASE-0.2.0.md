# macOS 0.2.0 release

Version **0.2.0 / build 14**, Public Beta, includes bundled engine **2.30.0**.
This release carries forward the harness engineering workflows introduced in
0.1.12, with updated version metadata and documentation.

Evaluate harnesses, review routing decisions and explore bounded optimization
in a native Mac workspace. The update includes suite diagnostics, held-out
baseline/candidate comparisons, guided tuning with saved judgments and reviewed
candidate adoption. Start with a credential-free setup check or offline practice
examples before running your own live experiments.

Available for Apple Silicon on macOS 14 or later. Provider charges apply to live
execution. See the [beta notes](BETA-NOTES.md) for supported behavior and
limitations. Setup checks do not measure model quality or guarantee improvements.

[Download the latest public beta](https://superqode.dev/downloads/macos/latest/SuperQode-arm64.dmg)
or install the Python CLI with `pip install --upgrade superqode`.
