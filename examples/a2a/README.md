# Public SuperQode Agent Card

`agent-card.json` is the checked-in publication artifact related to:

```text
https://superqode.dev/.well-known/agent-card.json
https://a2a.superqode.dev/.well-known/agent-card.json
```

Always prefer the **live** URLs above for discovery. Clients must call the
interface URL listed in `supportedInterfaces` (`https://a2a.superqode.dev`).

It is generated by the same official-SDK model used by the runtime server:

```bash
superqode serve a2a \
  --host 0.0.0.0 --allow-remote \
  --public-url https://your-a2a-interface.example.com \
  --export-agent-card examples/a2a/agent-card.json
```

Set `--public-url` to the operational A2A base URL clients should use.

## Status

| Surface | Status |
| --- | --- |
| Agent Card discovery | Published at `https://superqode.dev/.well-known/agent-card.json` |
| A2A operations | `https://a2a.superqode.dev` (public pilot, shortlist, anonymous permitted) |
| Path `/a2a` on the marketing host | Not an A2A endpoint |

The card advertises JSON-RPC and HTTP+JSON. Bearer is accepted as optional. Do
not put tokens or provider keys in the card. First call after idle can take
about a minute. Open calls use keyword matching; a signed key reads the
sentence.

## Smoke client

[smoke_client.py](smoke_client.py) discovers from a base URL, follows the
interface URL, and sends one message. No credential is required for the public
pilot:

```bash
uv run --extra a2a python examples/a2a/smoke_client.py https://a2a.superqode.dev
```

## Regeneration rules

- A token value is never written to the card. Supplying `--token` on an open
  deployment advertises the Bearer scheme without making it mandatory.
- Skill metadata on the card is product-facing. A remote bind serves
  `harness-shortlist` unless `--expose-harness` is set.
- Avoid whitespace around the interface URL when editing the JSON by hand.
- Regenerate and republish when the public interface URL, capabilities, or
  authentication policy change.
- CI checks export consistency for the checked-in artifact (`tests/test_a2a_bridge.py`).

Full guide: [docs/providers/a2a.md](../../docs/providers/a2a.md).
