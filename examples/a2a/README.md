# Public SuperQode Agent Card

`agent-card.json` is the checked-in publication artifact for
`https://super-agentic.ai/.well-known/agent-card.json`. It is generated by the
same official-SDK model used by the runtime server:

```bash
superqode serve a2a \
  --public-url https://super-agentic.ai/superqode/a2a \
  --token preview-only-value \
  --export-agent-card examples/a2a/agent-card.json
```

The token value is never written to the card; providing one adds the declared
Bearer security scheme. Regenerate and republish this file when the SuperQode
version, deployed HarnessSpec, public URL, capabilities, or authentication
policy changes. CI checks that the checked-in file matches the runtime output.
