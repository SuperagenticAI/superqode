# Public SuperQode Agent Card

`agent-card.json` is the checked-in publication artifact related to:

```text
https://super-agentic.ai/.well-known/agent-card.json
```

Always prefer the **live** URL above for discovery. Clients must call the
interface URL listed in `supportedInterfaces` (it may differ from the discovery
host). The live card may point at a temporary operational pilot.

It is generated by the same official-SDK model used by the runtime server:

```bash
superqode serve a2a \
  --public-url https://your-a2a-interface.example.com \
  --token preview-only-value \
  --export-agent-card examples/a2a/agent-card.json
```

Set `--public-url` to the operational A2A base URL clients should use.

## Status

| Surface | Status |
| --- | --- |
| Agent Card discovery | Published at `https://super-agentic.ai/.well-known/agent-card.json` |
| A2A operations | Follow the card’s interface URL (pilot; bearer auth) |
| Path `/superqode/a2a` on the marketing host | May still return maintenance until reverse-proxied |

The card advertises A2A 1.0 HTTP+JSON and Bearer authentication. Do not put
tokens or provider keys in the card.

## Smoke client

[smoke_client.py](smoke_client.py) discovers from a base URL, follows the
interface URL, and sends one authenticated message:

```bash
export SUPERQODE_A2A_TOKEN='<secret>'
uv run --extra a2a python examples/a2a/smoke_client.py https://super-agentic.ai
```

## Regeneration rules

- The token value is never written to the card; providing one adds the declared Bearer security scheme.
- Skill metadata on the card is product-facing (`SuperQode Harness`). The bound HarnessSpec still controls execution when the server is live.
- Avoid whitespace around the interface URL when editing the JSON by hand.
- Regenerate and republish when SuperQode version, public URL, capabilities, or authentication policy changes.
- CI checks export consistency for the checked-in artifact (`tests/test_a2a_bridge.py`).

Full guide: [docs/providers/a2a.md](../../docs/providers/a2a.md).
