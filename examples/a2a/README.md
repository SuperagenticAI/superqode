# Public SuperQode Agent Card

`agent-card.json` is the checked-in publication artifact for:

```text
https://super-agentic.ai/.well-known/agent-card.json
```

It is generated by the same official-SDK model used by the runtime server:

```bash
superqode serve a2a \
  --public-url https://super-agentic.ai/superqode/a2a \
  --token preview-only-value \
  --export-agent-card examples/a2a/agent-card.json
```

## Preview status

| Surface | Status |
| --- | --- |
| Agent Card discovery | Published (static file) |
| `https://super-agentic.ai/superqode/a2a/*` operations | Maintenance until the A2A Python process is reverse-proxied |

The card advertises A2A 1.0 HTTP+JSON and Bearer authentication. Clients that only need discovery can use the public URL; clients that need task execution should run a local `superqode serve a2a` or wait for the hosted interface to leave maintenance mode.

## Regeneration rules

- The token value is never written to the card; providing one adds the declared Bearer security scheme.
- Skill metadata on the card is product-facing (`SuperQode Harness`). The bound HarnessSpec still controls execution when the server is live.
- Regenerate and republish when SuperQode version, public URL, capabilities, or authentication policy changes.
- CI checks that this file matches the runtime export (`tests/test_a2a_bridge.py`).
